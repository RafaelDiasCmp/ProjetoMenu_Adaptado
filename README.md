
# Landing Page - Menu de Restaurante

Este projeto é uma landing page interativa para um menu de restaurante, projetada para proporcionar uma experiência agradável aos usuários ao visualizar as opções do cardápio. A página é responsiva e otimizada para diferentes dispositivos, como desktops, tablets e smartphones.

## Funcionalidades

- **Exibição de Menu**: Apresenta o menu completo do restaurante, dividido em categorias como entradas, pratos principais, sobremesas e bebidas.
- **Design Responsivo**: Layout adaptável que proporciona uma experiência consistente em todos os tamanhos de tela.
- **Interatividade**: Efeitos visuais e animações para uma navegação fluida e envolvente.
- **Fácil Navegação**: Links de âncora que permitem a navegação direta para diferentes seções do menu.
- **Imagens de Alta Qualidade**: Fotos dos pratos para ajudar os clientes a visualizar suas opções.
- **Chamada para Ação (CTA)**: Botões estrategicamente posicionados para reservas ou pedidos online.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página e marcação semântica.
- **CSS3**: Estilização da página, com uso de Flexbox e Grid para layout responsivo.
- **Bootstrap**: Framework CSS para facilitar o desenvolvimento e garantir a responsividade.
- **JavaScript**: Para adicionar interatividade e animações.
- **AOS (Animate On Scroll)**: Biblioteca para animações ao rolar a página.

## Como Visualizar o Projeto

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/usuario/restaurant-menu-landing-page.git
   ```

2. **Navegue até o diretório do projeto**:
   ```bash
   cd restaurant-menu-landing-page
   ```

3. **Abra o arquivo `index.html` no navegador**:
   Simplesmente clique duas vezes no arquivo ou arraste-o para o navegador.

## Estrutura do Projeto

- **index.html**: Página principal contendo a estrutura do menu e as seções do site.
- **css/style.css**: Arquivo de estilos personalizados.
- **js/main.js**: Scripts para interatividade e animações.
- **images/**: Diretório com as imagens utilizadas no site.
